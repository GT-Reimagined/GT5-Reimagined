[comment]: <> (## Using remote dependencies)

[comment]: <> (If you only plan on developing GT5R.)

[comment]: <> (### **You'll need**)

[comment]: <> (* IntelliJ Idea or Visual Studio Code &#40;OSS!&#41;)

[comment]: <> (* A copy of the [GT5 Reimagined]&#40;https://github.com/GT-ReimaginedGT5-Reimagined#41;  repository.)

[comment]: <> (### **Steps**)

[comment]: <> (* Run ./gradlew genIntellijRuns &#40;or ./gradlew genVSCodeRuns&#41; in GT5-Reimagined root.)

[comment]: <> (* Open folder in your editor, import as a gradle project in Idea.)

[comment]: <> (* Ensure project target is Java 17.)

[comment]: <> (* Run **runClient** configuration to run GT5R.)

[comment]: <> (## Using local dependencies.)

  * IntelliJ Idea (2020.3!) or Visual Studio Code/Neovim
  * GT5 Reimagined and GT-Lib
```console
   git clone --recurse-submodules https://github.com/GT-Reimagined/GT5-Reimagined
```
* Open folder in your editor, import as a gradle project in Idea.

* Run **Minecraft Client** configuration to run GTI. You might have to set classpath to GT5-Reimagined.main.
