## Description
GT5R has added Flint tools to be the go to early game tools.  The Flint Tools have more durability than the [Stone Tools](./stone_tools.md) but less than the metal tools.  Flint tools also introduces a new tool, the knife.  The knife can be used in some crafting recipes, as a weapon, or it can be used with other mods in preparing food.  Flint has a special ability of setting fire to mobs.  The Flint Sword, axe, and knife are great early game weapons as they have the chance to ignite enemy mobs giving extra burning damage.

## Usage
The flint tools are crafted similar to the stone tools with a single stick and the appropriate number of flint.
