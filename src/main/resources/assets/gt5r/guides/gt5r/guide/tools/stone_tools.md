## Description
Stone tools are available in GT5R but they have been modified.  All stone tools have much lower durability.  The stone tools have been designed as a starting tool with a limited use and to push the player into [Flint Tools](./flint_tools.md) and metal tools.  Stone tools do not have any special abilities.

## Usage
The stone tools can be crafted using the vanilla Minecraft recipes using cobblestone blocks and 2 sticks.  GT5R provides an alternate recipe using rocks and 1 stick.  There are a couple of special stone tools the [Red Granite and Black Granite Tools](./granite_tools.md).
